# cargo-unikernel-common

Shared guest-side PID-1 primitives for [`cargo-unikernel-init`](../cargo-unikernel-init):
filesystem/network bring-up, sysctl hardening, the seccomp denylist, and graceful shutdown.

Internal to [`cargo-unikernel`](https://codeberg.org/hacer-bark/cargo-unikernel) — not published or
intended for standalone use.
